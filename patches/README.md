# Патчі ORB-SLAM3

База — офіційний commit `4452a3c4ab75b1cde34e5505a36ec3f9edcdc4c4`. Патчі застосовуються до зовнішніх вихідників у файловій системі WSL; основний репозиторій містить лише невеликі diff-файли.

| Файл / налаштування | Категорія | Базовий запуск |
| --- | --- | --- |
| `orbslam3-cxx17.patch` | Сумісність компіляції: `mnFullBAIdx` використовується як лічильник, тому його тип змінено з `bool` на `int`; `++bool` заборонений у C++17. | Застосовується |
| `-include cstdint` у збиранні Pangolin v0.8 | Сумісність GCC 13: явне підключення типів фіксованої ширини, без змін вихідників Pangolin. | Застосовується як локальний прапорець CMake |
| `orbslam3-headless.patch` | Режим запуску: лише `bUseViewer=false` у стандартному `mono_tum`. | Застосовується, щоб не відкривати viewer |
| `orbslam3-offline-measurement.patch` | Окремий режим вимірювання: прибирає стандартний playback pacing і додає явний лічильник завершених кадрів. | Не застосовується до першого стандартного запуску |
| `orbslam3-shutdown.patch` | Відкладений варіант зміни очікування фонових потоків. Це не виправлення компіляції. | Не застосовується; спочатку перевіряється upstream-поведінка |

C++17 обрано для узгодження з конфігурацією Pangolin v0.8; версії ядра, Pangolin та стандарт після цього не змінювалися для обходу нових помилок. У базовому запуску залишаються стандартні shutdown і pacing. Власний shutdown-патч не слід вмикати без відтвореної проблеми та перевірки її конкретної причини.
