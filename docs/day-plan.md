# План на чотири дні

| День | Заплановані роботи | Умова завершення |
| --- | --- | --- |

Пізніше, після окремого дозволу: відеофайл, контракт worker, базова PostgreSQL/БД/API та простий перегляд проміжних результатів; початкові R1–R3. | Для Промпту 2 — справжня траєкторія, розріджені точки, проміжні дані, виміряні час і швидкість, відтворюваний запуск у WSL. Для всього дня — шлях відео worker → БД/API → браузер і збереження результатів. |

Бюджет першої спроби Промпту 2 — 2–3 години разом із підготовкою, залежностями та збиранням; початок і витрачений час фіксуються. Якщо траєкторії й точок немає, записати конкретний блокер і спроби та переглянути графік. API й UI не можуть замінити результат заглушкою; власний SLAM не розробляється.

На поточному етапі визначаються версії й необхідні залежності ядра, коротка перевірена послідовність і калібрування; підтримка завантаженого відеофайла належить Промпту 3. Великі матеріали й build зберігаються у файловій системі WSL, власні скрипти/патчі/документація — у поточному репозиторії. PostgreSQL/Nginx зараз не встановлюються.

Майбутні сервіси запускаються нативно у WSL; базово 2 незалежні HTTP compute-сервери, максимум 3 — проєктні числа. R7 не вилучається: відповідність автоматичного розширення лише процесами на одному вузлі формулюванню про ВМ/контейнери залишається відкритою. Публікацію на GitHub та push виконує користувач; агент створює лише перевірені локальні коміти з підтвердженою Git-ідентичністю.
