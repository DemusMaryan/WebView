Початок — 31 жовтня 2026 року. Поточний результат — тільки підготовка за Промптом 1: правила Git, огляд середовища, вимоги, план і майбутня архітектура. Промпти 2–5 зараз не виконуються; наведені нижче роботи ще заплановані.

| День | Заплановані роботи | Умова завершення |
| --- | --- | --- |
| 1 — 31 жовтня | Після окремого запуску наступного етапу: перевірений CV-прототип на реальному монокулярному відео; контракт worker; базова PostgreSQL/БД/API; простий перегляд проміжних результатів. Початкові R1–R3. | Прототип дає справжню траєкторію й розріджені точки; виміряні час і ресурси; відео проходить шлях worker → БД/API → браузер, результати збережені. |
| 2 — 1 листопада | Завершення користувацького сценарію: історія, нова задача, скасування, помилки й ліміти; авторизація та власність задач (R3–R4); доказ балансування (R5). | Наскрізний сценарій працює; чужі задачі захищені; дві реальні задачі паралельно виконуються на двох compute-серверах через Nginx з журналами доказу. |
| 3 — 2 листопада | HTTPS (R4), обмежена черга та приблизний ETA (R6), автоматичне розширення до 3 compute-серверів (R7), адміністративний моніторинг (R8). | Перевірені TLS, очікування та переповнення черги; третій сервер запускається автоматично, максимум дотримано; адміністратор бачить процеси й навантаження. |
| 4 — 3 листопада | Наскрізні перевірки R1–R8, виправлення, відтворюваний запуск і підготовка до захисту. | Для кожної вимоги збережений фактичний доказ; задокументовані команди, обмеження, результати перевірок і локальні коміти. |

Перша контрольна точка майбутнього етапу — реальний CV-прототип у перші 2–3 години. Якщо траєкторії й точок немає, спершу усунути блокер ядра та переглянути графік; API й UI не можуть замінити результат заглушкою. Тривалість — орієнтир, готовність визначається перевірками.

Залежності ядра, тестове відео та калібрування визначаються на наступному етапі. Встановлювати весь стек наперед не потрібно. Публікацію на GitHub та push виконує користувач; агент створює лише перевірені локальні коміти з правильною Git-ідентичністю.
